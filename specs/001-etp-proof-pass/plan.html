Interfaces:

  • Produces, in scripts/report-lib.mjs:
    • summariseVitest(json: object): {passed: number, failed: number, files: {name: string, passed: number, failed: number}[]};

Values from data: command string (the script's own constant, string); exit code (spawnSync().status, number, or null when killed, shown as "killed"); duration (performance.now() difference, number, shown in seconds); page path (each dist/**/*.html path, string); page size (fs.statSync().size, number, shown in KB); Vitest fields (testResults[].name, string; testResults[].assertionResults[].status, string passed or failed).
